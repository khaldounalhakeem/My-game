## 🚀 How to Play (On Google Drive)

### Step 1: Upload
1. Go to Google Drive: drive.google.com
2. Click "New" → "File upload"
3. Select one of the FIFA27_*.html files
4. Wait for upload to complete

### Step 2: Open
1. Double-click the file in Google Drive
2. It will open in preview
3. The game loads automatically

### Step 3: Play
1. Tap menu buttons (Ultimate Team, World Cup, etc.)
2. Tap "▶️ PLAY MATCH" to start
3. Tap action buttons: Shoot, Pass, Defend, Skip
4. Complete the match and get coin rewards
5. Return to menu

### Step 4: If Buttons Don't Work
Try the next version in the list above, starting from the top.
